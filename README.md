# 山禾颐品小程序

本仓库是山禾颐品唯一正式代码仓库的启动包。

## 开发入口

1. Codex 启动前先保留根目录 `AGENTS.md`。
2. 查看 `docs/TASKS.md` 得到下一项任务。
3. 只打开对应 `tasks/Mxx_*.md`。
4. 一个任务完成、测试、Git 提交后再进入下一项。

## 目录

- `apps/miniapp` 微信小程序
- `apps/admin` 管理后台
- `apps/api` API
- `docs` 产品/技术/状态文档
- `tasks` 低 Token 原子任务卡
- `.codex` Codex 项目配置/子智能体
- `scripts` Skill 安装与 Codex 启动脚本

## 第一条指令

```text
执行 tasks/M01_项目骨架.md。
严格遵守 AGENTS.md。
不要读取无关文档，完成后只输出摘要和测试结果。
```
