# 山禾颐品增量实现

## 工作范围

- 先读根目录 `AGENTS.md`、`PROJECT_CHECKPOINT.md`、当前模块在 `docs/MODULE_INDEX.md` 的条目和对应任务卡。
- 搜索目标模块现有实现后，只读取直接相关的 1～3 份业务文档、源码和测试。
- 一次只完成一个模块；优先复用现有 service、repository、共享类型和适配层。

## 实施方式

1. 将目标拆成可独立检查的 2～5 个小切片，确认每片的结果和边界。
2. 先完成依赖最少的切片；每片只改完成它所需的文件。
3. 涉及数据库时同步检查 Prisma schema、迁移、仓储和测试；遵守金额整数分、订单快照、库存流水与支付幂等等业务规则。
4. 每片运行最相关的验证；结束时按任务要求运行完整检查并查看 diff。
5. 更新 `PROJECT_CHECKPOINT.md` 中受影响的模块状态、剩余缺口和下一步。

不要为了计划读取整个仓库或全部 docs，不要把类型/模型/原型说成运行中的功能。
