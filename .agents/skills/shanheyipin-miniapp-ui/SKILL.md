# 山禾颐品小程序 UI

## 开始前

- 先检查 `PROJECT_CHECKPOINT.md`、`apps/miniapp/src/v12-ui-model.ts`、`v12-ports.ts` 及当前页面实现。
- 当前正式小程序尚无完整 uni-app 页面骨架；先核实目录现状，再只补当前任务需要的配置和页面。
- 页面使用项目选定的 uni-app + Vue 3 + TypeScript；商品和内容数据通过 Port/适配层，不在页面硬编码成真实业务数据。

## 已确认交互

- 底部导航顺序： 首页、分类、甄选、购物车、我的。
- 分类筛选：全部商品、应季甄选、礼盒、山野好物。
- 甄选页只呈现内容，不显示价格或加购操作。
- 首页入口和导航目标以 `v12-ui-model.ts` 为准。
- 图片使用可替换 OSS 对象键；不得把原型演示图片或虚构商品当正式资产。

确保触控目标易用、文本层级清楚、加载/空/错误状态明确。组件和页面不应引入未确认的业务规则；改动后运行相关组件/模型测试与构建验证。
