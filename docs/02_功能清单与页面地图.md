# 功能清单与页面地图

## 1. 小程序底部导航建议

```text
首页
分类
山野志
购物车
我的
```

“山野志”用于承载产地、工艺、人物和内容，不建议把品牌内容全部塞进商品详情。

## 4. 页面数量预估

- 小程序：约 45–60 个页面/子页面；
- Web 管理后台：约 60–90 个业务页面；
- 首期不要求一次开发完所有 P2 页面。
