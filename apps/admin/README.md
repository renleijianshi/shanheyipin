# 山禾颐品运营管理后台

## 当前状态

`web/` 是 Vue 3 + Vite 的运营后台入口，包含账号登录、经营概览、商品分类、SPU/SKU、素材上传、上下架、可恢复归档与商品 CSV 导出。`src/` 保留现有管理领域模型与验证逻辑。

管理 UI 使用同源 `/api/v1/admin/*` 请求；Vite 开发服务把 `/api` 转发到项目约定的 `127.0.0.1:3200`。登录后令牌保存在当前浏览器会话中，API 每次请求检查会话、管理员状态和对应 RBAC 权限。分类与商品改动写入 MySQL；公开小程序目录接口读同一份商品、SKU、分类数据。

当前管理 HTTP 层已覆盖认证、经营概览计数、SPU/SKU/分类读写、图片素材上传、上下架、可恢复归档、CSV 导出和公开目录读取。商品归档保留记录并强制下架，不删除历史订单快照。内容管理目前接入文章草稿/编辑/发布/撤回、封面上传和在售商品关联：后台路径为 `/api/v1/admin/stories`，公开列表/详情为 `/api/v1/stories`；页面与服务器均校验 `content.story.read/write`。视频上传/播放、专题，以及订单履约、售后、供应链、库存和报表尚未接入；不要将这些未接入模块当作可执行运营操作。

## 本机开发

内部商品联调使用隔离的本机数据库配置，不复用生产库。首次初始化和重复启动：

```powershell
pwsh -NoProfile -File .\scripts\internal-test.ps1 start
```

脚本只接受专用测试库 `127.0.0.1:3307` 和本机 API `127.0.0.1:3200`，并确保 H5 `127.0.0.1:5173`、后台 `127.0.0.1:5174` 可访问。测试管理员的本机凭据保存在 `%LOCALAPPDATA%\ShanheYipin\internal-test\access.txt`；不要复制到仓库或聊天。重复运行会保留现有测试编辑。打开 `http://127.0.0.1:5174`。未启动 API 时登录会显示明确的服务错误。

内部测试账号有真实写权限，API 按当前管理员权限逐次校验。它与开发模式下的只读预览账号分开；内部测试模式关闭预览登录，不能用预览数据冒充可写联调。

非内部测试的 Vite 开发模式仍可使用只读预览账号查看页面；预览数据标注为演示内容，所有写操作都会拒绝。预览账号不是内部测试管理员，也不是正式管理员。

## 验证

```powershell
npm run typecheck --workspace @shanheyipin/admin
npm run build --workspace @shanheyipin/admin
```

商品模块通过本机 MySQL/API 和 H5 完成了新增、SKU 测试价、图片上传/替换、上架/下架、归档恢复、重启保留和 CSV 内容验收。微信开发者工具、真机、AppID、生产素材与生产部署仍未验收；其余后台模块按进度文件逐项接入。
