# M01 项目骨架

## 目标
建立 monorepo/目录、基础 TypeScript 配置、lint/typecheck/test 框架；不实现业务。

## 只读优先
- `AGENTS.md`
- `docs/04_技术架构设计.md`
- `docs/14_AI开发交接说明.md`

## 执行
1. 先 `git status` / 搜索现有实现。
2. 只修改本任务相关文件。
3. 添加必要测试。
4. 运行相关 test/typecheck/lint。
5. `git diff --stat` + `git diff` 检查无关改动。
6. 更新 `docs/PROGRESS.md`。

## 输出
只报告：完成项、修改文件、测试结果、风险/阻塞。
